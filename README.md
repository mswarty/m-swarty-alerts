# M Swarty Alerts

Static site providing the public Privacy Policy and Terms and Conditions for the M Swarty Alerts personal SMS notification system. Hosted on GitHub Pages and used for Twilio A2P 10DLC campaign registration.

## Files

- `index.html` — Home page
- `privacy.html` — Privacy Policy
- `terms.html` — Terms and Conditions
- `styles.css` — Shared styles

## Publishing with GitHub Pages

1. Create a GitHub repository named `m-swarty-alerts`.
2. Push these files to the repository.
3. In GitHub, go to **Settings > Pages**.
4. Set **Source** to **Deploy from branch**.
5. Select the **main** branch and the **/(root)** folder.
6. Click **Save**.
7. Use the published URLs for Twilio:
   - `/privacy.html`
   - `/terms.html`

For example, if your GitHub username is `your-username`, the URLs will be:

- `https://your-username.github.io/m-swarty-alerts/privacy.html`
- `https://your-username.github.io/m-swarty-alerts/terms.html`
